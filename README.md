# Nexora Bank Management System

Deployment link of project: https://bank-frontend2-one.vercel.app/

## About the Project

Nexora Bank Management System is a database-driven banking application developed as a DBMS capstone project. It provides a centralized platform for managing customers, branches, accounts, transactions, loans and banking records.

The system is designed to organize banking data efficiently, provide an employee-based interface for managing operations, and maintain records of important activities through an audit log.

## Problem Statement

Traditional banking record management can become complex when customer information, accounts, loans and transactions are handled across disconnected systems. This can result in data inconsistencies, difficulty in tracking records and inefficient management.

Nexora Bank aims to address these challenges by providing a structured database-backed system that centralizes banking information, simplifies record management and supports organized banking operations.

## Features

- Dashboard for an overview of banking data
- Customer management
- Branch management
- Account management
- Transaction management
- Loan management
- Audit log tracking
- Reports and banking data overview
- Employee-based login and access

## Technology Stack

- **Frontend:** React.js, Vite
- **Backend:** Node.js, Express.js
- **Database:** MySQL-compatible TiDB
- **Authentication:** JWT
- **Deployment:** Render

## Database Modules

- Branch

- Transaction
